## 📝 Project Overview
The **iShop Calculator** is a data entry simulation tool. It focuses on gathering structured data (categorical item names and numerical prices) to demonstrate fundamental data processing and financial aggregation.

### 📊 Data Science Features:
* **Structured Collection:** Organizes raw user input into processable Python lists.
* **Numerical Analysis:** Performs real-time summation and formatting of financial data.
* **Data Flow:** Manages dynamic datasets through interactive loops.
